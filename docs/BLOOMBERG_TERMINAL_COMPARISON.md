## 一、Bloomberg Terminal 核心功能模块

### 1. 市场数据（Market Data）

| 功能 | Bloomberg 命令 | 说明 | TradeCat 覆盖 |
|:---|:---|:---|:---:|
| 实时报价 | `MONITOR` | 多资产实时价格监控 | ✅ |
| K 线图表 | `GRAPH` | 交互式技术图表 | ✅ |
| 深度行情（Level 2） | `MOSAIC` | Order Book 买卖盘深度 | ❌ |
| 期权链 | `OVDV` | 期权报价 + 希腊值 | ❌ |
| 期货曲线 | `CRV` | 期限结构可视化 | ❌ |
| 外汇报价 | `ALLQ` | 多银行报价聚合 | ⚠️ 仅 crypto |
| 固定收益定价 | `YCRV` / `SWPM` | 收益率曲线 + 掉期定价 | ❌ |

### 2. 分析（Analytics）

| 功能 | Bloomberg 命令 | 说明 | TradeCat 覆盖 |

| 相关性分析 | `CORR` | 资产间相关系数 | ❌ |

| 回测 | `BACK` | 策略历史回测 | ✅ |
| 因子分析 | `FA` | 多因子归因 | ❌ |

## 三、TradeCat 对个人 Crypto 交易者的覆盖度

对个人 crypto 交易者，Bloomberg 很多功能用不上（期权、固收、DCF 估值等）。

**真正需要补的**：

| 优先级 | 功能 | 说明 | 理由 |
|:---:|:---|:---|:---|
| P0 | 波动率分析 | 历史波动率 + 布林带 | 风控核心 |
| P1 | 事件日历 | 减半、ETF 审批、解锁 | 影响价格 |
| P2 | 社交情绪 | Twitter/Reddit 情绪指标 | 辅助决策 |
| P3 | 深度行情 | Order Book 可视化 | 短线交易 |
| P4 | 相关性分析 | BTC vs ETH vs SOL | 资产配置 |

**不需要补的**（对 crypto 无意义）：

- 期权链 / 期货曲线
- DCF 估值 / 基本面
- 固定收益定价
- Excel 插件

## 四、TradeCat TUI 设计建议

### 三页面规划（用户定义）

| 页面 | 内容 | Bloomberg 对标 |
|:---|:---|:---|
| **P1 行情** | 实时价格 + K 线 + 深度 | `MONITOR` + `GRAPH` + `MOSAIC` |
| **P2 模拟盘** | 持仓 + P&L + 交易记录 | `PORT` + `EMSX` |
| **P3 新闻** | RSS 信息流 + 情绪 | `NEWS` + `SOCM` |

### 设计原则

1. **简洁**：每个页面只做一件事，不堆功能
2. **实时**：数据自动刷新，不需要手动操作
3. **可操作**：看到信号能直接下单（虚拟盘）
4. **可迭代**：页面模块化，方便后续加功能

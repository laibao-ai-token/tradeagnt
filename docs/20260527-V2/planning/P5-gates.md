## 决策（已锁定）

### R 模式（5c + 5a + 5e）

| 模式 | 行为 | V2 |
|:---|:---|:---:|
| **R0** | 只读研究工具 | ✅ 保留 |
| **R1** | 分析 + thesis 草案，不落模拟盘 | ✅ 保留 |
| **R2 手动** | 草案 → **人点采纳** → 闸门 → 模拟盘 | ✅ **必做** |
| **R3 半自动** | **评估流水线**通过 → 自动 `submit-thesis` | ✅ **必做** |
| **R4 高自动** | R3 评估之上放宽条件/步骤（仍非实盘） | ✅ **必做**；可与 R3 共用闸门代码 |

- **切换**：左 Pi 区 / 全局模式器 — **R2 | R3 | R4**（及 R0/R1）。
- **渐进**：默认引导 **R2** → 熟悉后用 R3 → 再 R4；**随时可切回 R2**。
- **自动必评估**：R3/R4 **禁止裸自动**；评估结果写 **audit**，左栏摘要、右 TUI KPI。
- **执行**：R2 由 **人采纳** 触发 submit；R3/R4 由 **评估服务** 通过后调硬层 `submit-thesis`（Pi 不绕过闸门）。

## 决策（拍板后填写）

- **选定选项**：**P2-C（用户定制）** — 「像写代码一样做交易」的人机协作；非 V2 autopilot。
- **补充说明**：
  1. **谁用**：**人主导引导模型**，驱动 AI 分析市场并产出结论（对齐 P1 Trade-layer Claude Code）；**不是**无人值守 autopilot；**V3** 预留模型自主探索。
  2. **四六开**：人 ~40%（目标、标的、是否采纳、看结果）；AI ~60%（调行情/资讯/回测等工具、多步分析、起草假设）。
  3. **默认从哪进**：**TUI** 为默认壳；Agent/工具在 TUI 背后或会话内被唤起（具体交互 P3 拆）。
  4. **人看什么**：关注 **是否赚钱、关键浅显指标**；Agent 推理过程 → **步骤卡片/摘要**，禁止把 Codex 级长上下文直接塞给人。
  5. **技术待决（不阻塞 P2 产品锁定）**：是否引入轻量开源 Agent 框架（用户提及 **Pi**）承载 trade agent——建议 **P8 技术选型** 再定；V2 可先 manifest + 现有 CLI/脚本，框架可插拔。

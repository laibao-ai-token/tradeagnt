## 决策（拍板后填写）

- **选定选项**：**A+（用户定义）** — 非官方 Public 整包复刻，也非纯 TUI demo 延伸。
- **补充说明（用户原意摘要）**：
  - **出发点**：一切围绕 **Agent** 设计，模拟 **彭博终端交易员** 的工作方式——在充足上下文里看行情、资讯、回溯，再形成判断。
  - **形态**：类似 **Codex / Claude Code 类 Agent** 的「工具 + 上下文 + 多步推理」，把经验复制到 **Trade Agent**（本仓 tradeagnt）。
  - **我们提供**：把上下文备好；暴露可调用工具（行情、信号、资讯、回测摘要等）；Agent 调用后产出**结构化分析**，辅助决策，让 pipeline 更顺。
  - **执行层**：纸面/simulation（非实盘）；具体「分析 → thesis → 落单」在 P3/P5 拆，但不违背 Agent 中心。

### 建议写入 PRD 的一句话定位

> **tradeagnt V2 = Agent 原生的交易研究与纸面执行 Harness**：为 Agent 提供彭博交易员级的只读工具链与上下文；Agent 调用工具完成分析并提交可审计决策；系统负责闸门与模拟成交，人不走主路径。

### V2.0 明确不做（与上述一致）

- 实盘、签名、读密钥
- 以人类 TUI 点击为主路径
- V2.0 内建完整彭博终端级 UI（只做 Agent 工具 + 可选监控）
- 整仓替换为官方 Public / 公开表唯一信号源

### 架构共识（2026-05-28 用户确认）

- **不用自研 Agent 运行时**；用 **Pi 做打底**（harness：对话 + tool loop + Skills/Extensions）。
- **左栏 = Pi**；**右栏 = tradecat TUI**（数据看板，辅助人决策）。
- **双向关系**：
  - **人 → 右 TUI**：看盘、选标的、看 KPI/盈亏。
  - **人 → 左 Pi**：对话、下意图、看步骤摘要。
  - **Pi → 工具**：`tradecat_get_*` 等（研究/执行类工具，R 档位搁置）。
  - **Pi ← 右 TUI**：Agent **可从 TUI 读当前上下文**（如选中 symbol、面板 KPI 快照、可见行情摘要）— 具体字段 P3 末条待列清单。

| 区域 | 运行时 | 角色 |
|:---|:---|:---|
| **左** | **Pi** + trade Skills/Extensions | Agent 编排；**非**自研 loop |
| **右** | **tradecat TUI** | 人的决策看板 + **Agent 可读的数据源** |

Pi 负责 harness；tradeagnt 负责 **TUI 数据** 与 **trade 工具** 实现。

## 决策（已锁定）

- **架构**：**不自研 Agent**；**Pi 打底**；左 Pi + 右 tradecat TUI；TUI = 人看板 + **Pi 可读上下文**。
- **步骤列表**：① 双栏启动 → ② 选标的（右为主，左可确认）→ ③ 模式占位 → ④ 左 Pi 对话/意图 → ⑤ Pi tool loop → ⑥ 左结论 + 右 KPI。
- **3a**：**左 Pi 对话为主**；右栏可选「发送到 Agent」（非必须）。
- **3b**：V2.0 Pi **仅研究类工具**（`tradecat_get_*`、读 TUI 快照）；**不含**模拟下单（等 R 档位 / P5）。
- **3c**：**不自动下一轮**；必须人再发起。
- **3-TUI→Pi 最小字段**：
  - `symbol`（当前标的）
  - `market`（crypto / us_stock 等）
  - `last_price` 或等价最新价
  - `paper_pnl` 或「赚不赚钱」一行 KPI
  - `signal_direction` + `signal_freshness` 各一行（来自本地 signal）
  - （可选）`timeframe` / 当前剖面名
- **补充说明**：Pi 与 Python 嵌入方式 → P8；右 TUI 实现读快照接口 → 实现阶段（M1+）。

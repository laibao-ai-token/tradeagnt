# tradeagnt 独立版说明

本仓库为 **tradeagnt**（单体 `src/tradecat`），不是完整 [TradeCat](https://github.com/tukuaiai/tradecat) 微服务栈。

| 版本 | 含义 |
|:---|:---|
| **v0.8.x** | 演示封板（TUI 双市场 + 模拟盘 + on-demand 行情） |
| **v1.0+** | 独立产品线：`data/` 数据目录、去 `services/` 依赖 |

快速开始见根目录 `README.md`；迁移见 [MIGRATE_v0.8_to_v1.0.md](./MIGRATE_v0.8_to_v1.0.md)。

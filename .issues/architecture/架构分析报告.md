## 四、各服务模块职责清单

### 4.1 data-service (核心服务 - 加密货币数据采集)

| 文件路径 | 职责 |
|:---|:---|
| `src/__main__.py` | 服务入口，进程调度器，管理ws/metrics/backfill子进程 |
| `src/config.py` | 配置管理，数据库URL/代理/数据源配置 |
| `src/collectors/ws.py` | WebSocket K线实时采集，3秒批量写入，缺口巡检 |
| `src/collectors/metrics.py` | 期货指标采集 (持仓量/多空比/主动买卖比等5个API) |
| `src/collectors/backfill.py` | 历史数据补齐 (ZIP优先 + REST兜底) |
| `src/adapters/timescale.py` | TimescaleDB 存储适配，COPY批量upsert |
| `src/adapters/cryptofeed.py` | Binance WebSocket 适配器 |
| `src/adapters/ccxt.py` | CCXT REST API 适配器 |
| `src/adapters/rate_limiter.py` | 全局限流器 (1800/min)，跨进程文件锁 |

### 4.2 trading-service (核心服务 - 指标计算)

| 文件路径 | 职责 |
|:---|:---|
| `src/__main__.py` | 服务入口，Engine.run() 调度 |
| `src/core/engine.py` | 主引擎，IO→Compute→Storage 流程编排 |
| `src/core/io.py` | IO层，从TimescaleDB读取K线，缓存装配 |
| `src/core/compute.py` | Compute层，并行计算 (thread/process/hybrid) |

## 五、关键技术特性

| 特性 | 实现 |
|:---|:---|
| **高性能写入** | TimescaleDB COPY命令 + 临时表 upsert |
| **智能限流** | 令牌桶 + 文件锁跨进程同步 (1800/min) |
| **并行计算** | ThreadPool/ProcessPool/Hybrid 三种模式 |
| **规则引擎** | 129条规则，9大分类，稳定ID索引 |
| **冷却机制** | SQLite持久化，防重复推送 (默认300s) |
| **连续聚合** | TimescaleDB CAgg 自动聚合多周期 |
| **缺口检测** | 后台线程自动巡检 + ZIP/REST补齐 |
| **数据缓存** | 全局缓存500条/K线窗口，LRU策略 |

# Issue Templates Index

Quick reference for choosing the right template.

## Templates

| Template | Use When | File |
|----------|----------|------|
| bug.md | Reporting a bug or defect | [bug.md](./bug.md) |
| feature.md | New feature request | [feature.md](./feature.md) |
| refactor.md | Code refactoring or tech debt | [refactor.md](./refactor.md) |
| architecture.md | Architecture planning | [architecture.md](./architecture.md) |
| gstack-skills-usage.md | Using GStack skills workflow | [gstack-skills-usage.md](./gstack-skills-usage.md) |

## Quick Start

1. **Bug**: Something doesn't work → use `bug.md`
2. **Feature**: Add new capability → use `feature.md`
3. **Refactor**: Improve existing code → use `refactor.md`
4. **Architecture**: System design changes → use `architecture.md`

## Naming Convention

- Use lowercase: `bug.md`, `feature.md`, `refactor.md`
- Issue files in backlog: `{priority}-{short-description}.md`
  - Example: `C1-RSS-新闻采集静默失败.md`, `H1-硬编码路径.md`

## 三、分析任务

### Batch 1: 指标使用分析

#### Task 1.1: 统计指标被规则引用情况

**Input**:
- `trading-service/src/indicators/` 所有指标文件
- `signal-service/src/rules/` 所有规则文件

**Output**:
- 每个指标被引用次数统计
- 未被引用的指标列表

**Steps**:
1. 遍历所有指标，提取指标名称
2. 遍历所有规则，搜索指标引用
3. 统计每个指标的引用次数
4. 生成报告

**Verification**:
- 统计报告已生成
- 数据可验证

**Dependencies**: 无

---

#### Task 1.2: 统计指标计算耗时

**Input**:
- `trading-service/src/indicators/` 所有指标文件
- 测试数据

**Output**:
- 每个指标的计算耗时
- 高耗时指标列表

**Dependencies**: Task 1.1

---

### Batch 2: 规则触发分析

#### Task 2.1: 统计规则触发频率

**Input**:
- `libs/database/services/signal-service/signal_history.db`
- 分析时间范围（如最近 30 天）

**Output**:
- 每条规则的触发次数
- 从未触发的规则列表
- 触发率极低的规则列表

**Steps**:
1. 连接 signal_history.db
2. 按规则 ID 分组统计
3. 计算触发频率
4. 生成报告

**Verification**:
- 统计报告已生成
- 数据可验证

**Dependencies**: 无

---

#### Task 2.2: 分析规则依赖关系

**Input**:
- `signal-service/src/rules/` 所有规则文件

**Output**:
- 规则之间的依赖关系
- 可合并的相似规则

**Dependencies**: Task 2.1

---
